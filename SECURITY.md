# Security Policy

This prototype is intended for evaluation and synthetic demo data only.

Do not submit real private incident reports, personal data or sensitive photographs to an unconfigured or publicly shared deployment.

Do not commit API keys. Report security issues privately to the repository maintainer rather than publishing secrets or exploitable personal data in an issue.

Before production use, add and independently test authentication, server-side resource authorization, restrictive data and storage rules, global rate limits, secure persistent audit storage, deletion/retention policies, and a threat model covering malicious report text and uploaded media.
